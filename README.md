# 📝 Key Meeting Notes

**Turn meeting discussions into organized notes, clear decisions, and actionable next steps.**

Key Meeting Notes is a lightweight, browser-based meeting management application designed to help users capture important discussions, organize meeting information, track action items, and revisit saved notes whenever needed.

Built using HTML, CSS, and JavaScript, the application provides a simple and accessible way to manage meeting records without requiring a complicated installation process.

🔗 **Live Application:** https://albertdavis-ad.github.io/key-meeting-notes/

## ✨ Features

### 📋 Structured Meeting Management
- Create and organize meeting notes.
- Add meeting titles and dates.
- Record attendee information.
- Keep meeting information structured and easy to review.

### 💡 Key Points and Decisions
- Capture important discussion points.
- Document decisions made during meetings.
- Keep essential information separate from general notes.

### ✅ Action Items
- Record tasks and follow-up activities.
- Organize next steps to support accountability.
- Make meeting outcomes easier to revisit.

### 🔍 Search and Filtering
- Search saved meeting notes.
- Find relevant meetings more efficiently.
- Reduce the time spent looking through previous records.

### 💾 Local Data Persistence
- Save meeting information using browser local storage.
- Retain saved notes across page refreshes in the same browser.
- Access locally stored meeting information without needing a backend database.

**Note:** Locally stored notes are browser- and device-specific. They do not automatically synchronize across different devices or browsers.

### 📤 Export Meeting Notes
- Export meeting notes as text files for easy sharing and archiving.
- Use the browser's print functionality to save supported meeting content as a PDF.

### 🎨 Simple and User-Friendly Interface
- Clean, accessible web-based design.
- Organized presentation of meeting information.
- Lightweight application that runs directly in a modern web browser.

## 🎯 Project Objectives

- Improve the organization of meeting documentation.
- Make important discussions and decisions easier to retrieve.
- Encourage clear ownership of follow-up activities.
- Reduce the risk of losing important meeting information.
- Demonstrate how lightweight web technologies can support everyday productivity.

## 🚀 Getting Started

### Option 1: Use the Live Application

Open the application directly:

**https://albertdavis-ad.github.io/key-meeting-notes/**

No installation is required to access the hosted application.

### Option 2: Run Locally

**Prerequisites**
- A modern web browser.
- Git installed on your computer, if you want to clone the repository.

**Step 1 — Clone the repository**

```bash
git clone https://github.com/albertdavis-AD/key-meeting-notes.git
```

**Step 2 — Open the project directory**

```bash
cd key-meeting-notes
```

**Step 3 — Launch the application**

Open `index.html` in your preferred browser.

Alternatively, open the project folder in Visual Studio Code and use your preferred local preview method.

No package installation or backend server is required for the standalone application.

## 📖 How to Use

1. Open Key Meeting Notes in your browser.
2. Create a meeting record and enter the relevant meeting details.
3. Document key discussion points and decisions.
4. Add action items and follow-up tasks.
5. Save the meeting information.
6. Use search or filtering to locate previously saved meetings.
7. Export notes as a text file or print them to PDF when needed.

*The available actions depend on the controls implemented in the current application interface.*

## 🔐 Data and Privacy

- Meeting records are stored locally in the browser when local storage is used.
- The application does not provide automatic cloud synchronization.
- Clearing browser site data may remove locally saved meeting records.
- Export important meeting information regularly if you need a separate backup.
- Avoid storing confidential meeting information on shared devices.

## 💡 Why This Project?

Meetings create value when discussions lead to decisions and decisions lead to action.

Yet important details can disappear in lengthy conversations, scattered notes, and forgotten follow-ups. Key Meeting Notes provides a straightforward way to capture what matters, preserve meeting records, and make the next steps easier to identify.

The project demonstrates how a simple web application can support better organization, documentation, and follow-through.
